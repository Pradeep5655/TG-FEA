# TG-FEA: Trust-Gated Byzantine-Robust Federated Hybrid Ensemble

## Overview

This repository contains the implementation of the research project:

**Trust-Gated Byzantine-Robust Federated Hybrid Ensemble (TG-FEA) for IoT Intrusion Detection**

The project aims to build a robust federated learning framework capable of defending against Byzantine attacks while detecting IoT botnet attacks using deep learning.

---

## Dataset

Dataset used:

- N-BaIoT Dataset

Current dataset summary:

- IoT Devices: 9
- CSV Files: 89
- Features: 115
